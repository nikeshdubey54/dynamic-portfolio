# Module 12 – Dashboard Module

## 1. Module Overview

The Dashboard Module provides a secure and responsive management area for the portfolio website.

It allows the administrator to manage portfolio content from a centralized dashboard.

The dashboard includes management sections for:

- Projects
- Skills
- Messages
- Services

The dashboard is designed to work properly across desktop, tablet, and mobile devices.

---

## 2. Objectives

The main objectives of this module are:

- Create a professional dashboard interface.
- Provide management pages for portfolio content.
- Provide responsive layouts for different screen sizes.
- Improve usability on mobile devices.
- Prevent horizontal scrolling and layout breaking.
- Maintain consistent styling across dashboard pages.
- Provide clear action buttons and management tables/cards.

---

## 3. Dashboard Features

### 3.1 Dashboard Home

The dashboard home page provides an overview of the portfolio management system.

It includes:

- Statistics cards
- Quick action cards
- Management navigation
- Responsive layout

---

### 3.2 Project Management

The project management section provides complete project management functionality.

Features include:

- Project listing
- Create project
- Edit project
- Delete project
- Project image display
- Project information display
- Project action buttons
- Responsive project cards on mobile

---

### 3.3 Skills Management

The skills management section provides functionality to manage portfolio skills.

Features include:

- Skill listing
- Skill icon display
- Skill proficiency percentage
- Progress bar
- Create/Edit/Delete actions
- Responsive skill cards on mobile

---

### 3.4 Message Management

The message management section allows the administrator to manage contact messages.

Features include:

- Message listing
- Sender information
- Email information
- Subject display
- Read/Unread status
- Message actions
- Responsive message cards on mobile

---

### 3.5 Services Management

The services management section allows the administrator to manage portfolio services.

Features include:

- Service listing
- Service image
- Service title
- Service description
- Create/Edit/Delete actions
- Responsive service cards on mobile

---

# 4. Responsive Design

A complete responsive system was implemented for the dashboard.

The dashboard supports:

- Desktop screens
- Tablet screens
- Mobile screens
- Small mobile screens
- Very small screens

The desktop management tables are displayed on larger screens.

On mobile devices, the tables are replaced with responsive management cards.
