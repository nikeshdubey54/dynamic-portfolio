# Project Goal

The objective of this project is to build a modern, responsive, dynamic, scalable and production-ready Portfolio Content Management System using Django.

The system should allow the administrator to manage all portfolio content through an admin dashboard while visitors can explore projects, blogs, skills, services and contact information.

The project should also support appointment booking and online payments.
