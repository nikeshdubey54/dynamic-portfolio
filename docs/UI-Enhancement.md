Interview Questions
Q1. Why do we use position: sticky for a navbar?

Answer: It keeps the navigation visible while scrolling, improving usability and allowing users to access navigation at any point on the page.

Q2. Why use Django's {% url %} template tag instead of hardcoded URLs?

Answer: It generates URLs dynamically from named routes. If a route changes later, templates continue to work without manually updating every link.

Interview Questions
Q1. Why did you separate the About section into reusable UI components?

Answer

It improves readability, maintainability, and consistency. Reusable components make future updates easier without affecting other parts of the application.

Q2. Why use consistent card styling across Education, Experience, Certifications, and Achievements?

Answer

Using a consistent design system creates a professional user experience, improves visual hierarchy, and makes the interface easier to scan for recruiters.
